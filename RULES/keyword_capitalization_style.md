## CRITICAL: Keyword Capitalization - Capital Case Only

**Why This Matters:**
- Consistency signals authentic, professionally-written resume
- ALL existing keywords are Capital Case (Title Case)
- Lowercase keywords look like they were added by AI (inauthentic)
- Hiring managers notice inconsistent capitalization

## The Rule

✅ **ALWAYS use Capital Case (Title Case) for keywords:**

```
WRONG (Lowercase):
  statistical modeling
  churn prediction
  customer analytics
  
RIGHT (Capital Case):
  Statistical Modeling
  Churn Prediction
  Customer Analytics
```

## Examples from Resume

**Current (Correct) Style:**
```
ML & Statistics: Scikit-learn, XGBoost, SHAP, Hypothesis Testing, Model Calibration, 
Imbalanced Classification (SMOTE), Churn Prediction, Risk Modeling, NumPy, SciPy, PyTorch

Cloud: AWS(EC2, S3, Lambda, DynamoDB), Azure, GCP

Data Engineering & Deployment: FastAPI, Docker, MLflow, pgvector, PostgreSQL, pandas, 
SQLAlchemy, Pydantic, Docker Compose, GitHub Actions, pytest
```

Notice: All words capitalized (Hypothesis Testing, Imbalanced Classification, Model Calibration, etc.)

## When Adding Keywords

Every keyword added should follow this pattern:

```
FloatMe JD has: "kubernetes, airflow, sagemaker"
Add to resume as: "Kubernetes, Airflow, SageMaker"

Meds.com JD has: "statistical modeling, churn prediction"  
Add to resume as: "Statistical Modeling, Churn Prediction"
```

## Multi-Word Keywords

Both words capitalized, even small words:
```
CORRECT:
  Statistical Modeling
  Customer Analytics
  Subscription Retention
  Pricing Analysis
  Risk Modeling
  
WRONG:
  Statistical modeling
  customer analytics
  subscription retention
  pricing analysis
  risk modeling
```

## Special Cases

- **Acronyms:** Keep as-is (AWS, XGBoost, SHAP, SMOTE, NLP, RAG)
- **Python libraries:** Keep original casing (pandas, scikit-learn, PyTorch)
- **Company products:** Keep original casing (SQLAlchemy, PostgreSQL, GitHub Actions)
- **Everything else:** Capital Case

## Verification Checklist

Before submitting resume:
- ✅ All newly added keywords are Capital Case
- ✅ Existing keywords still Capital Case
- ✅ No lowercase keywords mixed in
- ✅ Consistency throughout Skills section
- ✅ Feels genuine and authentic
