Data Science Engineer

About the Role:
We're looking for a Data Science Engineer to join our team and build ML-powered products.

Responsibilities:
- Develop and deploy machine learning models to production
- Work with Python, SQL, and cloud platforms (AWS/GCP)
- Build ETL pipelines and data warehouses
- Collaborate with product teams on data-driven features
- Mentor junior engineers

Requirements:
- 2+ years of production machine learning experience
- Strong proficiency in Python, SQL, and data analysis
- Experience with machine learning frameworks (TensorFlow, PyTorch, scikit-learn)
- AWS or GCP experience (EC2, S3, Lambda, BigQuery)
- Knowledge of Docker, Kubernetes, or microservices
- Experience with Git and CI/CD pipelines

Nice to Have:
- Open source contributions
- Personal projects with real-world impact
- Experience with distributed systems (Spark, Hadoop)
- Portfolio website or GitHub profile
- Publications or technical writing
